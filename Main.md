# Выводы по разным подходам

Базовые сравнения — против constant-baseline своего датасета: Yandex $\tau=0.045, lr=0.003$ (Recall 0.1296, NDCG 0.0527, Hitrate 0.3693), Amazon $\tau=0.065, lr=0.002$ (Recall 0.0388, NDCG 0.0116, Hitrate 0.0523).

### Constant
- Постоянная температура на всё обучение — служит baseline для всех остальных подходов на обоих датасетах.
- Yandex: [[09.06 Константа на 30 эпохах, baseline]] — $\tau=0.045, lr=0.003$.
- Amazon: [[21.06 Amazon constant]] — $\tau=0.065, lr=0.002$; [[24.06 Amazon constant part 2]] подтвердила широким перебором ($\tau\in[0.01,1.0]$), что оптимум лежит именно в этой узкой окрестности.

### Linear
- Линейный рост $\tau$ от min к max по эпохам.
- Yandex: [[08.06 Переезд на кластер + 30 эпох]] — в районе baseline, выигрыша нет (-0.0% Recall).
- Amazon: [[24.06 Amazon linear]] — **лучший простой подход на Amazon**: min=0.06, max=0.07 → +0.4% Recall, +1.7% NDCG, +2.6% Hitrate.

### Cos
- Косинусное изменение $\tau$ по эпохам.
- Yandex: [[16.06 Косинус на 30 эпохах]] — стабильно лучше baseline (+0.9% Recall, +0.8% NDCG, +1.2% Hitrate), но плато к ~20-й эпохе.
- Amazon: [[24.06 Amazon cos]] — хуже baseline (-2.3% Recall). Подход не переносится на Amazon.

### Param (Sigmoid)
- Сигмоидальный параметрический $\tau$.
- Yandex: [[18.06 Sigmoid Param]] — хуже baseline (-1.3% Recall, -2.1% NDCG).
- Amazon: [[25.06 Param Amazon]] — **лучший по NDCG/Hitrate на Amazon**: min=0.06, max=0.075 → +0.6% Recall, +2.8% NDCG, +2.9% Hitrate.
- Вывод: асимметрично работает между датасетами — противоположный Cos по знаку эффекта.

### Cos Per User (PerUser)
- Косинус, независимый для каждого пользователя.
- Yandex: [[18.06 Cos Per User на 30 эпохах]] — второй лучший результат по Recall на Yandex (+1.3%).
- Amazon: [[25.06 Cos Per User Amazon]] — ни один из ~13 проверенных конфигов (включая перебор lr) не обошёл baseline; лучший результат практически на уровне (-0.1% Recall, +0.8% NDCG).
- Вывод: per-user персонализация температуры полезна на Yandex, но даёт незначительный выигрыш на Amazon.

### Shifted Cos Per User
- Yandex: [[19.06 Shifted Cos Per User]] — **лучший результат по Recall среди всех подходов на Yandex** (+1.4%); [[20.06 Shifted Cos part 2]] показал, что дальнейшее понижение $\tau_{min}$ только ухудшает результат.
- Amazon: [[26.06 Shifted Cos Per User Amazon]] — обходит baseline (max=0.065, shift=-0.4, scale=0.3, lr=0.0018, негативы 10k+20k → +0.9% Recall, +1.5% NDCG, +1.4% Hitrate).
- Вывод: в отличие от простого Cos Per User, добавление сдвига/масштаба (плюс пониженный lr и другие негативы) позволяет подходу выигрывать на обоих датасетах.

### MACL (MACLoss tau)
- Yandex: [[20.06 MACLoss tau]] — **лучший NDCG/Hitrate на Yandex** (+1.5%/+1.5%) при Recall +1.2%.
- Amazon: [[25.06 MACL Amazon]] — лучший найденный конфиг (bt=0.34, lc=-0.05) сравнялся с baseline по Recall (+0.0%), но улучшил NDCG (+1.6%) и Hitrate (+1.3%).

**Итог:** на Yandex лучший вариант по Recall — Shifted Cos Per User, по NDCG/Hitrate — MACL. На Amazon по Recall лучший — Shifted Cos Per User (+0.9%), по NDCG/Hitrate — Param (+2.8%/+2.9%), Linear близко по всем метрикам. Простой Cos Per User на Amazon выигрыша не даёт, но добавление сдвига/масштаба (с пониженным lr и другими негативами) выводит Shifted Cos Per User в лидеры по Recall на обоих датасетах. В целом на Amazon хорошо заходят как монотонные схемы (Linear/Param/MACL), так и Shifted Cos Per User.
